{{- else }}
  kubectl port-forward svc/{{ include "supermixer.fullname" . }} 8080:{{ .Values.service.port }}

The first sign-in is the bootstrap admin: see the log of the first replica to start
  kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }} | grep -i password

Creating Supabase stacks (provisioning) runs `docker compose` and isn't supported
here: register existing stacks instead.
